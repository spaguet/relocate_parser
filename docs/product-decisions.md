# Продуктовые решения relocate_helper

> Документ фиксирует ответы на открытые решения из [TZ_telegram_parser_ai.md](../TZ_telegram_parser_ai.md), раздел 15.  
> Единственный источник правды для продуктовых параметров при реализации промптов 1–18.

**Версия:** 0.1  
**Дата создания:** 2026-07-25  
**Ответственный за документ:** владелец проекта  
**Следующий пересмотр:** 2026-08-25 (или после ответов на блокирующие вопросы)

---

## Легенда статусов

| Статус | Значение |
|--------|----------|
| `pending` | Требует решения владельца; реализация не должна зашивать значение в код |
| `proposed` | Безопасный конфигурируемый default; можно использовать в dev/staging до подтверждения |
| `confirmed` | Утверждено владельцем |
| `deferred` | Сознательно отложено; не блокирует локальную разработку |

### 2.2 Пороги публикации фактов (proposed)

| Тип сведений | Автопубликация | Min confidence | Min независимых sources | Иначе |
|--------------|----------------|----------------|-------------------------|-------|
| Бытовые цены и услуги | да | 0.75 | 2 | `needs_review` |
| Адреса и контакты организаций | да | 0.70 | 1 | `needs_review` |
| Инструкции, рекомендации (non-sensitive) | да | 0.72 | 1 | `needs_review` |
| Юридические, миграционные | **нет** | — | — | всегда `needs_review` |
| Медицинские | **нет** | — | — | всегда `needs_review` |
| Финансовые (курсы, налоги) | **нет** | — | — | всегда `needs_review` |

**Независимый источник** = разные записи `sources`, не разные сообщения одного чата (ТЗ §2.2).

Конфиг: admin UI «Publication thresholds»; изменения аудируются.

### 2.3 Пороги достаточности ответа (proposed)

Порог достаточности **может быть ниже** порога публикации (ТЗ §2.2, §6.1).

| Сценарий | Min evidence | Min confidence (aggregate) | Поведение |
|----------|--------------|----------------------------|-----------|
| Ответ по опубликованной карточке | 1 карточка + ≥1 fact | 0.65 | генерация ответа |
| Ответ по фактам (цены) | ≥1 fact; для «типичной цены» — ≥2 observations или карточка | 0.60 | генерация с оговоркой о малом числе наблюдений |
| Ответ по chunks (fallback) | ≥2 chunks из ≥1 source | 0.55 | генерация с пометкой «единичные упоминания» |
| Sensitive domain | ≥1 fact/card + human-reviewed **или** refusal | — | без autopublish; warning обязателен |
| Противоречие без снятия | — | — | отказ или диапазон (ТЗ §6.2) |
| Нет данных | 0 | — | ранний отказ **без** дорогой модели |

Конфиг: `SUFFICIENCY_*` settings + admin overrides.
